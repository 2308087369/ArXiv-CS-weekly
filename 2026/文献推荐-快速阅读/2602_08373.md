## 1. 摘要

具身智能规划器的核心任务是根据高层指令（如“清理厨房中打翻的油渍”）生成一系列可在物理环境中执行的动作序列。传统的端到端大模型规划虽然在语义连贯性上表现卓越，但在涉及复杂安全约束的场景中，往往会出现“语义幻觉”或“安全盲点”。例如，模型可能会建议混合漂白剂和氨水来清洁地板，这在自然语言语境下看似合理，但在物理现实中会生成致命的氯气。

现有的安全保障机制多为“被动守门人”模式，即利用另一组 LLM 作为评论家或使用硬编码规则对生成计划进行拦截。这种模式存在两大局限：首先，概率性的评论家（LLM-as-a-Judge）依然存在幻觉风险；其次，简单的拒绝（Reject）无法提供建设性的反馈，导致智能体在复杂约束下频繁陷入“拒绝执行”的僵局，任务成功率低下。

**VIRF (Verifiable Iterative Refinement Framework)** 的提出，可以看作一种安全机制从“被动拦截”向“主动协同”的工程化转移。

## 2. 核心架构：VIRF的三大支柱

VIRF 的成功建立在三个互补的支柱之上：可溯源的公理合成（Traceable Axiom Synthesis）、VLM 层叠感知（VLM-Cascade Perception）以及并行化的神经符号推理（Neuro-symbolic Reasoning）。

该架构不仅仅是一个验证器，而是一个完整的认知闭环。它接受感知模块的 ABox（环境状态）和知识库的 TBox（安全公理），通过迭代精化循环，将 LLM 生成的自然语言计划转化为经过逻辑验证的安全行动序列。

## 3. 关键机制：可溯源公理合成与知识获取

构建形式化验证系统的最大障碍在于“知识获取瓶颈”，即如何将海量、模糊且动态的现实世界安全准则转化为机器可读的逻辑公理。VIRF 通过一种半自动化的、“人机协同”的离线工作流解决了这一问题。

<div align="center">
  <img src="../../Resource/第六期/VIRF-The Traceable Axiom Synthesis workflow, a semi-automated, human-in-the-loop process for building the TBox from unstructured texts.png" width="90%" alt="Figure 2: Traceable Axiom Synthesis workflow">
  <br>
  <em>Figure 2: The Traceable Axiom Synthesis workflow. 半自动化、人机协同的 TBox 构建过程。</em>
</div>
<br>

该工作流不同于运行时随机注入文本的 RAG（检索增强生成）方法，而是在设计阶段进行的严谨过程。
1.  **AI 合成器**：从经过验证的文档（如安全手册、化学品安全说明书）中检索相关片段，并草拟符合曼彻斯特语法（Manchester Syntax）的 OWL 2 逻辑公理。
2.  **人类仲裁**：人类专家充当仲裁者，通过验证“公理-证据对”来确保逻辑的严密性与真实性。

研究数据显示，该工作流在短短两天内合成了 92 条高质量安全公理，显著扩展了智能体对特殊危害（如化学混合、儿童误食、热油喷溅）的认知覆盖。

**表 1：VIRF 知识获取工作流与传统方法及原生 LLM 方法的对比分析**

| 知识获取维度 | 传统手工编码 | 运行时随机 RAG | VIRF 公理合成 |
| :---- | :---- | :---- | :---- |
| **构建速度** | 极慢（数月/数年） | 实时（秒级） | 快速（数日） |
| **逻辑严密性** | 极高（专家确保） | 极低（LLM 生成） | 极高（人类审计） |
| **可解释性/溯源性** | 间接 | 无 | 直接（公理链接至源文档） |
| **维护成本** | 极高 | 低 | 中等（支持模块化更新） |

## 4. 感知与推理：VLM层叠与并行验证

### 4.1 三阶段 VLM 层叠感知管道

形式化推理的有效性高度依赖于其对当前物理环境的“符号接地”准确性，即 ABox（断言成分）的真实性。VIRF 设计的 VLM-Cascade 感知管道旨在消除 LLM 对环境状态的幻觉。

感知过程分为三个有序阶段：
1.  **目标检测（Detect）：** 确定场景中的物体及其边界框。
2.  **属性精化（Attribute-Refine）：** 识别物体的精细状态（如“灶台是否开启”、“容器是否密闭”）。
3.  **关系精化（Relation-Refine）：** 建立物体间的空间与功能关联（如“儿童距离热源的具体关系”）。

这种层叠式设计体现了“安全优先”的原则。尽管感知延迟达到 168.4 秒，远高于普通检测器的 85.2 秒，但其准确率（76.3%）和对危险细节的捕捉能力是实现 0% 有害动作率（HAR）的必要前提。对于安全关键型系统，漏报危险（False Negative）的代价远超延迟增加的代价。

### 4.2 并行化神经符号推理引擎

在获得感知的 ABox 和知识库 TBox 后，VIRF 启动迭代精化循环。LLM 学徒生成的初始计划被转化为一系列待验证的逻辑查询。为解决描述逻辑推理（Description Logic Reasoning）在长序列规划中的计算负担，VIRF 采用了一种多线程并行验证架构。

系统并不顺序检查计划的第 1 步至第 N 步，而是为每一步创建并行的推理线程。每个线程模拟执行前的世界状态并调用 Pellet 推理器进行验证。这种架构将验证时间从动作序列长度的线性增长，优化为单步最长推理时间的常数级（约 3 秒），极大地提升了系统的实时响应能力。

## 5. 交互模式：从“拒绝”到“教学”的对话机制

VIRF 的核心创新在于其生成的“因果教学反馈”。当逻辑导师发现计划违反安全公理时，它不仅指出哪一步是错误的，还会解释底层的逻辑冲突。

例如，在处理化学品任务时，逻辑导师会提供如下形式的反馈：
> “步骤 3 不安全。你试图混合‘清洁剂 A’和‘清洁剂 B’。根据安全公理 SA-102，含有次氯酸钠的物质与酸性物质混合会产生有害氯气。场景感知显示‘清洁剂 B’含有柠檬酸。请修改计划以避免此类混合。”

这种深层次的因果信息赋予了 LLM 学徒进行“创造性修复”的能力，而不仅仅是简单的避让。实验证明，失去因果反馈后（即仅告知不安全），计划器遭受了高达 33.0% 的假阴性率（FNR），即智能体因为无法理解错误根源而直接放弃了本可以完成的任务。

## 6. 实验评估与实证发现

研究者在一套包含化学混合、热油处理、儿童看护等高难度家居安全任务的基准测试上对 VIRF 进行了一系列严苛评估。

### 6.1 核心性能指标：HAR 与 GCR

实验重点关注两个相互竞争的指标：有害动作率（Hazardous Action Rate, HAR）和目标条件达成率（Goal-Condition Rate, GCR）。

**表 2：VIRF 在复杂安全任务中的表现对比**

| 实验架构方案 | 有害动作率 (HAR) | 目标达成率 (GCR) | 修复迭代次数 (均值) |
| :---- | :---- | :---- | :---- |
| 原生 LLM (Zero-shot) | 38.5% | 52.1% | N/A |
| LLM + 静态规则注入 | 12.4% | 61.2% | N/A |
| **VIRF (完整版)** | **0.0%** | **77.3%** | **1.1** |

实验结果证明，VIRF 实现了完美的 0% HAR，彻底消除了不安全行为，同时其 GCR（77.3%）显著优于所有基准模型。平均仅需 1.1 次修正迭代即可达成安全且有效的规划，这体现了教学对话的高效性。

### 6.2 消融研究

*   **VIRF-Reject**（仅拒绝不解释）：导致高假阴性率，证明了因果反馈的必要性。
*   **VIRF-Manual**（手工常识库）：无法应对专业安全场景（如化学品识别）。
*   **VIRF-RAG**（检索增强）：因知识污染和随机性导致了 8.5% 的 HAR，佐证了“设计时公理合成”的优越性。

## 7. 讨论：模型规模与安全机制的深度演化

### 7.1 模型规模与推理能力边界

*   **7B 模型的“推理下限”**：实验发现，当使用 7B 参数规模的模型作为学徒时，VIRF 的表现出现大幅下滑。尽管逻辑导师提供了精准的反馈，但 7B 模型往往无法处理这些逻辑约束。这表明，神经符号框架虽然能提供“外骨骼”，但内部模型必须具备一定的基础推理能力（Reasoning Threshold）才能实现有效协作。
*   **72B 与 Gemini-2.5 的平权效应**：在高参数量模型对比中，72B 开源模型在 VIRF 的支持下表现出与 Gemini-2.5 相当的安全性。这暗示了通过外部逻辑锚点，可以使稍逊一筹的开源模型在特定安全领域达到甚至超过封闭领域尖端大模型的表现。

### 7.2 二阶洞察：安全机制的深度演化

从 VIRF 的研究中可以提炼出若干关于人工智能安全与自治演进的深层趋势：

1.  **感知与推理的“不平衡博弈”**：VIRF 接受了感知层的高延迟（168.4s）以换取推理层的确定性。这预示着未来的智能体架构可能会采用类似于人类思维的“系统 1（快速直觉响应）与系统 2（慢速逻辑校准）”的分层结构。
2.  **知识的“可溯源性”**：VIRF 的 Traceable Axiom Synthesis 工作流通过将每一条曼彻斯特语法的公理链接回其原始安全文档，完美契合了欧盟 AI 法案等监管趋势中对可审计性的要求。
3.  **安全性与创造性的辩证统一**：精准的因果反馈反而激发了模型的“合规创造力”。当模型知道“混合 A和 B 是危险的”这一具体原因时，它会更积极地寻找替代路径，从而提升了整体任务的成功率。

## 8. 结论与推荐总结

VIRF 框架不仅是一项技术创新，更是对大语言模型局限性的深刻回应。它证明了构建可信、安全且高效的具身智能系统不需要放弃生成式模型的多样性，而是需要为其配备一套“形式化逻辑的舵机”。

通过公理合成、层叠感知和教学对话，VIRF 在复杂的家居安全任务中实现了 0% 的有害动作率和行业领先的目标达成率。这一成果为 2026 年及以后的人工智能安全研究奠定了坚实的基础，预示着未来的智能体将不仅仅是语义上的“博学者”，更是物理世界中可验证的、严谨的“行动者”。

**深度洞察汇总表**

| 核心模块 | 关键机制 | 核心价值 | 数据证明 |

| **逻辑导师** | 基于因果教学的反馈 | 使模型理解错误根源，而非仅逃避错误 | 修正迭代次数仅 1.1 次 |
| **公理合成** | AI 辅助的人类审计工作流 | 突破知识获取瓶颈，建立可溯源知识库 | 2 天内合成 92 条验证公理 |
| **VLM 层叠** | 三阶段特征提取 | 消除感知幻觉，为逻辑推理提供真实 ABox | 有害动作率降至 0% |
| **并行验证** | 多线程推理加速 | 解决描述逻辑推理的延迟问题，支持实时规划 | 单步验证仅需约 3 秒 |
